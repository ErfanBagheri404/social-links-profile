# Social links profile

![Design preview for the Social links profile challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Social links profile** challenge - a responsive component built from the provided design.

**Live demo:** https://erfan-revenant.github.io/social-links-profile/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/social-links-profile.git
cd social-links-profile
```

Open `index.html` in a browser. Nothing to install or compile.
